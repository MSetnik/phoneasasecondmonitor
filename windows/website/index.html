Phone as a Second Monitor

Windows preview

Try your phone as a second display for a Windows PC. This build is for testing on Windows 10 22H2 or Windows 11 with an Intel or AMD x64 processor.

Download Windows installerThe preview installer does not yet carry an MCODE publisher signature.

Connect your phone

  1. Run the installer. Setup requires administrator approval and uses a virtual display driver signed by SignPath Foundation.
  2. Open Phone as a Second Monitor from Start. Connect both devices to the same trusted Wi-Fi network.
  3. Scan the QR code, tap Connect device, then approve the device on your PC. Drag a window onto the new display.

The 20-minute demo begins on first launch. The optional €14.99 lifetime purchase uses live Stripe Checkout.
